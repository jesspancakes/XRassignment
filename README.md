# XR 26 Class Assignment

For my project, I want to teach the user the basics of sewing!

This will include learning about basic sewing tools and simple stitches.
To do this, I will use hand tracking to mimic the holding of tools.
Upon picking up a tool, the pop-up will appear, telling the player what the item is and what it is used for. 
Additionally, the player will have a book of stitches to choose from, containing instructions on how to complete the stitch. 
After selecting a stitch, the player must hold the needle in the xr space, and guide it through the correct spot on the fabric to sew. 
After finishing a row of one stitch, it will be marked as "learned"
This forces the player to do one stitch multiple times, learning through repetitive action.
The stitch book will also teach the player about when to use certain stitches; whether they are functional and strong, or mainly for decoration and detail.

The tools in the game will include :
 - different needle types
 - fabrics
 - thread types
 - scissors
 - pins
 - pin cushions
 - needle threaders
 - stitch rippers
 - thimbles
 - safety pins
 - buttons
   
The stitches will include :
 - running stitch
 - back stitch
 - whip stitch
 - blanket stitch
 - cross stitch
 - chain stitch
 - ladder stitch

To create the project I will use the Godó Hands project as a base, as I want to have hand tracking and interactions in my game. 
I will also use Godot XR Tools, as well as the xr25 and xr26 repos.
